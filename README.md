# minidb

A small database engine built from scratch in Python.

## Features (planned)
- Table storage (week 2)
- Hash index (week 3)
- SQL parser (week 4)
- B+ tree index (weeks 5-7)
- Query planner (week 8)
- Cache and storage (week 9)
- Dashboard (weeks 10-11)

## How to run tests
python -m pytest -v
